## Разведка (по заметкам прошлой итерации, `IMPROVEMENT_BACKLOG.md` B003)

Прошлая итерация (77_12) оставила зацепку: документ `docs.cntd.ru/document/3656309`
не фетчился ни разу в B003-серии и упомянут как эталонный NPA для 77_13/14/15/19.
Проверил его полнотекстовым поиском на "пенсионер"(в контексте работающих),
"зубн"/"протез", "телефон", "27 401", "292" — НИ ОДНО совпадение не найдено по
существу (единственное совпадение "пенсионер" — не по теме, про ветеранов
правоохранительных органов). Документ оказался "Закон города Москвы №70 от
03.11.2004 О мерах социальной поддержки..." — даёт только общие категории
получателей (инвалиды ВОВ, боевых действий и т.д.) и рамочные статьи (1-3), но
НЕ содержит конкретных статей о выплатах/льготах для 77_13/14/15 — они, видимо,
устанавливаются подзаконными актами/постановлениями, как и предыдущие кейсы
(77_1 и др. использовали закон только для номенклатурного подтверждения
категории, суммы — из отдельного постановления).

Через WebSearch нашёл целевую страницу для 77_14 ("Бесплатное изготовление и
ремонт зубных протезов"): `sp53.mos.ru/lgotnoe-zuboprotezirovanie` — сайт
стоматологической поликлиники №53, подведомственной Департаменту
здравоохранения Москвы (поддомен mos.ru, в рамках allowlist "mos.ru — отдельно
из-за объёма московских региональных мер"). Страница дословно ссылается на
"Законом № 70" (= document/3656309, эталонная NPA-ссылка для этой строки —
структурное подтверждение правильности выбранного NPA, хоть сам закон и не
даёт деталей) и явно называет "Департамента здравоохранения города Москвы" —
совпадает с эталонным department.

Также пробовал найти точную сумму для 77_15 (телефонная компенсация, эталон
292₽) — WebSearch дал противоречивые цифры (218/264/444/528₽ из разных
источников/дат), точного 292 не нашёл ни на одной проверенной странице
(dszn.ru/news/145 — старая новость 2011 года без актуальной суммы, pgu2/faq
страница — SPA-шелл без серверного рендеринга, не фетчится статикой). Поэтому
в ЭТОЙ итерации беру 77_14 (не 77_15) — там golden-значения текстовые
("бесплатно"), не число, что делает поле воспроизводимым без гадания с суммой.
