## Гипотеза

Три предыдущих попытки (iteration_3 2026-07-31, Yandex Search API 403,
SearXNG → федеральная норма без лимита мощности — не совпадает с golden)

возможно, полный текст статьи о льготах там, где предыдущие фетчи (via
proxy/SearXNG) его не увидели из-за обрезания.

## Что сделано

1. cntd.ru недоступен ни напрямую, ни через `RU_PROXY_URL` в этой сессии
   (подтверждено — `direct FAILED`), только `via_jina` (см. B007).
2. `docs.cntd.ru/document/3691928/titles/` → получил оглавление с явными
   marker'ами по статьям, включая `Статья 4. Налоговые льготы` →
   `65E0IS`. Зафетчил `docs.cntd.ru/document/3691928/titles/65E0IS`
   (действующая редакция на 01.11.2025/01.01.2026) — получил **полный**
   текст ст. 4 целиком (14 пунктов, не обрезано).
3. Пункт 5 ст. 4: "ветераны боевых действий, инвалиды боевых действий -
   за одно транспортное средство, зарегистрированное на граждан указанных
   категорий" — **безусловное освобождение по одному ТС, БЕЗ ограничения
   по мощности двигателя**. Ни в одном из 14 пунктов статьи (включая
   действующую редакцию 2026 года) нет отдельного ограничения "до 200
   л.с." для категории ветеранов/инвалидов боевых действий — единственное
   упоминание мощности в статье относится к СОВСЕМ ДРУГОЙ, универсальной
   льготе п.9 ("лица, имеющие автомобили... до 70 л.с.", не связано с
   категорией ветерана).
4. Для контроля дополнительно сверил СТАРУЮ редакцию (2008, зеркало
   klerk.ru) — тот же результат: п.5 без ограничения по мощности,
   единственное реальное ограничение в части 3 статьи — "льготы не
   распространяются на водные, воздушные ТС, снегоходы и мотосани" (тип
   ТС, не мощность).
5. Golden `MeasureTerms` для `77_vbd_11/12/13`: "Освобождение от уплаты
   налога в отношении одного транспортного средства с мощностью
   двигателя до 200 л.с." — сверено напрямую с `docs/меры_автоагент_2.xlsx`
   (read-only openpyxl, лист "вбд", строки 77_vbd_11/12/13). **"До 200
   л.с." не подтверждается ни действующей, ни исторической редакцией
   Закона №33** — ни в самом п.5, ни где-либо в статье 4 применительно к
   этой категории. Это четвёртая по счёту (после iteration_3,
   Yandex Search API, SearXNG) неудачная попытка найти документ,
   совпадающий с golden.
6. Для `77_vbd_14/15/16` (земельный налог, golden `MeasureTerms`:
   "Уменьшение налоговой базы на 1 млн ₽ кроме земельных участков,
   сдаваемые в аренду") — параллельно проверил: (а) `docs.cntd.ru/document/3656284`
   (Закон о земельном налоге) — не имеет постатейного оглавления в
   `/titles/`, `via_jina` даёт только список изменяющих документов, тело
   статей не рендерится (та же лазy-load проблема, что не решается
   marker-трюком для этого конкретного документа); ранее (iteration_3,
   2026-07-31) этот документ был зафетчен ПОЛНОСТЬЮ через прокси (75864
   симв.) и не содержал "ветеран"/"боевых действий" ни разу — подтверждено
   повторно логически (структура документа не изменилась); (б) федеральная
   норма НК РФ ст. 391 п.5 подп.4 — уменьшает базу на кадастровую
   стоимость **600 кв.м участка**, не на фиксированную сумму (WebSearch,
   consultant.ru/klerk.ru зеркала статьи) — не совпадает с golden "1 млн
   ₽"; (в) WebSearch дал агрегаторное утверждение "Москва дополнительно
   вычитает 1 000 000 ₽ для ветеранов боевых действий" (похоже на
   правду, комбинация федеральной 600 кв.м + региональной 1 млн ₽), но
   ни один первоисточник (сам НПА) с этой цифрой не найден — только
   вторичные агрегаторы (nalkod.ru, t-j.ru) и заголовки статей
   КонсультантПлюс за login-стеной (не читается без подписки).
