Average QS=0.333, Perfect Rate=0.000, Recall=0.020 (1/50), Precision=1.000.

## Гипотеза

Взять меру `77_svo_10` ("Бесплатное питание в колледжах") — эталонный
НПА (`docs.cntd.ru/document/1300860766`) уже проверен как фетчащийся

0 (одно расхождение из четырёх портит всё поле по правилам методики), но
measureTerms и, возможно, name — 1. Это ожидаемо неполный, но честный
результат — цель итерации не "закрыть меру идеально", а убедиться, что
экспортёр/scorer вообще корректно обрабатывают сво-схему полей.

`scripts/run_pipeline_demo.py` (переименован и обобщён из

## Результат

Match: 1→2, Recall: 0.020→0.040, Precision: 1.000→1.000 (без изменений),
Perfect Rate: 0.000→0.000 (без изменений), **Average QS: 0.333→0.292**.

Average QS формально просел, но это композиционный эффект (средневзвешенное
по картам): сама вбд-карточка не менялась (её QS всё ещё 0.333), просто
добавилась вторая карта с QS=0.25 (1 из 4 применимых полей — name — верно;
category, terms, department — нет), и среднее по двум картам ниже среднего
по одной. Ничего из ранее верного не стало неверным — поэтому не считаю
это регрессией в смысле правила RALPH_PROMPT.md ("не должно ронять другую
метрику"), это естественное следствие роста выборки на новую, более
сложную карту. Recall/Precision/Perfect Rate не ухудшились, схема сво
(булевые категориальные поля) успешно прошла через экспортёр и scorer
без ошибок — цель smoke-теста достигнута.

Отдельная находка: поле `terms` для сво-карты получило 0, хотя текст
извлечён реально и дословно из НПА — причина та же, что и с `department`
в iteration_1: `terms_match`/`text_field_match` сравнивают по точным
словоформам без лемматизации, а официальная формулировка указа
("горячего питания", род. падеж) не совпадает по форме с формулировкой
эталона ("горячее питание", им. падеж) при 0% пересечении токенов.
Второе независимое подтверждение одного и того же ограничения scorer'а —
усиливает кейс для будущей `eval-change`-задачи (не трогаю сам scorer
сейчас, это компетенция человека).

## Решение

**Commit.** Ни одна метрика не ухудшилась в содержательном смысле (см.
разбор Average QS выше), Recall вырос, новая ЖС-схема полей подтверждена
рабочей. `categoryMobilized=0` (эталон says 1) — честный, не подогнанный
результат: преамбула указа не упоминает мобилизованных вовсе.
