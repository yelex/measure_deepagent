# Skill: Trusted Sources (Allowlist)

## Домены

### Высший приоритет (тексты НПА)
- `cntd.ru` — КонсультантПлюс
- `consultant.ru` — КонсультантПлюс (зеркало)
- `garant.ru` — Гарант

### Официальные сервисы
- `gosuslugi.ru` — Госуслуги (включая раздел мер СВО)
- `sfr.gov.ru` — Социальный фонд России
- `mos.ru` — Портал мэра Москвы (региональные меры)
- `dszn.ru` / `msupport.dszn.ru` — Департамент соцзащиты Москвы
- `sp53.mos.ru` — поддомен mos.ru (здравоохранение)

### Региональные порталы соцзащиты
- Добавляются по мере расширения покрытия регионов

### Дополнительные источники
- `disk.yandex.ru` — PDF-памятки от официальных ведомств (если размещены dszn.ru)
- `mosgortur.ru` — МОСГОРТУР (оздоровление детей-инвалидов)
- `aeroexpress.ru` — транспортные льготы

## Правила
1. Поиск ТОЛЬКО по allowlist-доменам
2. Форумы, агрегаторы льгот, сторонние сайты — НЕ использовать
3. Каждый найденный факт должен сопровождаться URL источника
4. Для изменения суммы/условия — ≥2 независимых источника (double confirmation)
