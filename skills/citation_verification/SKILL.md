# Skill: Citation Verification

## Принцип
Каждое извлечённое поле должно сопровождаться дословной цитатой из источника.

## Правила верификации

1. **Цитата обязательна** — поле без цитаты = поле не подтверждено → null
2. **Цитата дословная** — копия текста из источника, без перефразирования
3. **Минимальная длина** — достаточно для однозначной идентификации факта
4. **Проверка** — код проверяет наличие цитаты в тексте источника

## Двойное подтверждение (high-impact findings)
Для изменений суммы выплаты или условий назначения:
- Нужно ≥2 независимых источника (например, текст НПА + портал соцзащиты)
- Если только 1 источник → находка помечается `low_confidence`
- `low_confidence` не идёт в основной реестр

## Исключения из двойного подтверждения
- Изменение только ведомства-исполнителя (низкий риск) — достаточно 1 источника
- Найдено точное совпадение суммы и условия в тексте федерального закона — 1 источник
